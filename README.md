# Homebrew tap for Psephi

```bash
brew install psephi-app/psephi/psephi
```

- `Formula/psephi.rb` — the `psephi` command-line client ([psephi-app/psephi-cli](https://github.com/psephi-app/psephi-cli)).
  Releases open a PR here automatically; formulas are not edited by hand.
- `Casks/` — reserved for the macOS app.
